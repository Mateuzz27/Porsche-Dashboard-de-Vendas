# Porsche-Dashboard-de-Vendas

Projeto de análise de dados desenvolvido com auxílio do ChatGPT e do Canvas, utilizando HTML, CSS e JavaScript para criar uma dashboard interativa de vendas da Porsche.

O dashboard apresenta KPIs, gráficos comparativos e filtros dinâmicos para analisar o faturamento por modelo, o desempenho por estado e os métodos de pagamento, transformando dados brutos em insights para responder a perguntas de negócios.

Com um design executivo inspirado na identidade visual da Porsche, o projeto destaca a importância da visualização de dados clara e objetiva para facilitar a interpretação de indicadores, identificar oportunidades comerciais e apoiar a tomada de decisões estratégicas.

Principais recursos:

Indicadores de desempenho (KPIs).

Filtros interativos por modelo, ano, estado, cidade e método de pagamento.

Gráficos de faturamento e rankings comparativos.

Geração dinâmica de insights de negócios.

Tabela detalhada de vendas.

Interface responsiva com HTML, CSS e JavaScript.
